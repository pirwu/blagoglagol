# Благоглаголъ

Святой язык программирования. Доступно на Windows 10.

## Запуск

python blg.py пример.blg

или

blg пример.blg

## Пример

азъ рече число главная() {
    глаголи "Во имя Отца, и Сына, и Святаго Духа!"
    
    для день := 1 до 7 твори
        глаголи "День ", день, " творения"
    покончи
    
    возврати 0
}

главная()
